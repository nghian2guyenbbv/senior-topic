1. MySQL Connection Config

Basic Spring Boot YAML configuration to connect to a MySQL database:

spring:
  application:
    name: outbox-transaction

  datasource:
    url: jdbc:mysql://localhost:3306/outbox_db
    username: outbox_user
    password: outbox_pass
    driver-class-name: com.mysql.cj.jdbc.Driver

  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    properties:
      hibernate:
        dialect: org.hibernate.dialect.MySQLDialect
💡 Spring Boot auto-detects the dialect in Hibernate 6+ / Spring Boot 3+. You may not need to set dialect manually.

2. Hibernate ddl-auto Modes

Controls how Hibernate manages the database schema on application startup.

Mode Creates Tables Updates Schema Drops on Startup Drops on Shutdown
none ❌❌❌❌
validate ❌❌❌❌
update ✅✅❌❌
create ✅❌✅❌
create-drop ✅❌✅✅

Mode Details

none — Hibernate does nothing. You manage DDL completely yourself.

validate — Checks entity vs DB schema. Throws error on mismatch. No changes made.

update — Creates missing tables/columns. Never drops anything. ⚠️ Not for production.

create — Drops and recreates all tables every startup. All data is lost.

create-drop — Same as create, also drops all tables on shutdown. Best for tests.

Recommended by Environment

EnvironmentRecommended Mode
Developmentupdate or create
Testingcreate-drop
Productionnone or validate
⚠️ Note: The database/schema itself must already exist. Hibernate creates tables but does not create the database. 
CREATE DATABASE outbox_db;

3. Important Hibernate Configurations

show-sql & format-sql

spring:
  jpa:
    show-sql: true
    properties:
      hibernate:
        format_sql: true        # pretty-print SQL
        use_sql_comments: true  # shows JPQL source as comment

open-in-view (always disable!)

spring:
  jpa:
    open-in-view: false   # default is true — keep session open per HTTP request (bad!)
⚠️ Always set open-in-view: false. Keeping it true can cause lazy loading issues and performance problems.

Naming Strategy

spring:
  jpa:
    hibernate:
      naming:
        physical-strategy: org.hibernate.boot.model.naming.PhysicalNamingStrategyStandardImpl
StrategyaggregateId →
Default (SpringImplicitNaming)aggregate_id (snake_case)
StandardaggregateId (as-is)

Batch Inserts (Performance)

spring:
  jpa:
    properties:
      hibernate:
        jdbc:
          batch_size: 50
        order_inserts: true
        order_updates: true

Batch Fetch Size (N+1 Fix)

spring:
  jpa:
    properties:
      hibernate:
        default_batch_fetch_size: 20

5. HikariCP with RDBMS

HikariCP is database-agnostic — it works with any RDBMS via JDBC. Just swap the URL and driver.

# MySQL
url: jdbc:mysql://localhost:3306/outbox_db
driver-class-name: com.mysql.cj.jdbc.Driver

# PostgreSQL
url: jdbc:postgresql://localhost:5432/outbox_db
driver-class-name: org.postgresql.Driver

# SQL Server
url: jdbc:sqlserver://localhost:1433;databaseName=outbox_db
driver-class-name: com.microsoft.sqlserver.jdbc.SQLServerDriver

# Oracle
url: jdbc:oracle:thin:@localhost:1521:orcl
driver-class-name: oracle.jdbc.OracleDriver

# H2 (in-memory)
url: jdbc:h2:mem:testdb
driver-class-name: org.h2.Driver

6. R2DBC — Reactive Programming

HikariCP uses JDBC (blocking). For reactive applications (Spring WebFlux), use R2DBC instead.

Same MySQL Database
        │
        ├── JDBC Driver (mysql-connector-j)   → Blocking    → HikariCP
        │
        └── R2DBC Driver (r2dbc-mysql)        → Non-blocking → r2dbc-pool

Dependencies

<!-- pom.xml -->
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-data-r2dbc</artifactId>
</dependency>

<dependency>
  <groupId>io.asyncer</groupId>
  <artifactId>r2dbc-mysql</artifactId>
</dependency>

<dependency>
  <groupId>io.r2dbc</groupId>
  <artifactId>r2dbc-pool</artifactId>
</dependency>

JDBC vs R2DBC Comparison

JDBC + HikariCPR2DBC + r2dbc-pool
Programming modelBlockingNon-blocking ✅
Spring moduleSpring Data JPASpring Data R2DBC
RepositoryJpaRepositoryReactiveCrudRepository
Return typesList<T>, Optional<T>Flux<T>, Mono<T>
Connection poolHikariCPr2dbc-pool
Hibernate support✅ Full❌ Not supported
Maturity🏆 Very matureNewer, fewer features

Code Difference

// JDBC (Blocking) — holds a thread
List<OutBox> result = repository.findAll();

// R2DBC (Reactive) — non-blocking
Flux<OutBox> result  = repository.findAll();
Mono<OutBox> single  = repository.findById(1L);

7. R2DBC Connection Pool Config

Spring Boot auto-configures r2dbc-pool with defaults. Only configure when you need to tune.

Minimal Config (defaults are fine)

spring:
  r2dbc:
    url: r2dbc:mysql://localhost:3306/outbox_db
    username: outbox_user
    password: outbox_pass

Full Tuned Config

spring:
  r2dbc:
    url: r2dbc:mysql://localhost:3306/outbox_db
    username: outbox_user
    password: outbox_pass
    pool:
      initial-size: 5           # connections created on startup
      max-size: 20              # max connections in pool
      max-idle-time: 30m        # close idle connections after 30 min
      max-acquire-time: 5s      # timeout waiting for a connection
      max-life-time: 1h         # max lifetime of a connection
      validation-query: SELECT 1  # health check query
